# Multi-User Portfolio Platform

A full-stack web application where users can create professional portfolios and share them through a public profile link.

## Tech Stack

**Backend**

* Java 21
* Spring Boot
* Gradle

**Frontend**

* React
* TypeScript
* Vite

**Other Tools**

* Docker
* Cursor
* Claude

##  Features (MVP)

* User signup & login
* Dashboard for managing portfolio
* Profile editing
* Project CRUD (create, edit, delete)
* Public portfolio page (`/u/:username`)

##  Project Structure

```
backend/   → Spring Boot API
frontend/  → React application
```

## Development Plan
